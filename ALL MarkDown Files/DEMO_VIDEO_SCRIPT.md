## Recording Tips

| Tip | Details |
|---|---|
| **Resolution** | Record at 1920×1080 or higher |
| **Zoom** | Zoom into elements before clicking (use Chrome accessibility zoom or OBS crop) |
| **Speed** | Speak at a clear, confident pace — not too fast |
| **Browser** | Use Chrome Incognito to avoid personal bookmarks showing |
| **Freighter** | Pre-unlock Freighter before recording to avoid fumbling |
| **TX Speed** | Testnet transactions typically confirm in 5-10 seconds |
| **Retakes** | Record multiple takes — you only need the best 90 seconds |
