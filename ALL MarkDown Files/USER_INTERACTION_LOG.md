## How to Find Transaction Hashes

**Method 1: TicketChain TX Feed**
- After any transaction, the bottom-right toast shows the tx hash
- Copy the hash and paste into Stellar Expert

**Method 2: Freighter Wallet History**  
- Open Freighter extension → click the wallet address
- Scroll to Activity section → hover a transaction → copy hash

**Method 3: Stellar Expert Direct Search**
- Go to https://stellar.expert/explorer/testnet
- Search by wallet address to see all transactions

**Verification URL pattern:**  
`https://stellar.expert/explorer/testnet/tx/{TX_HASH}`
